# 🏍️ Moto Type Racer

A fast-paced, cyber-themed arcade typing racing game built with React, Vite, Tailwind CSS, and HTML5 Canvas[cite: 1]. Accelerate your motorcycle down neon-lit highways by typing incoming words quickly and accurately[cite: 1, 2]. Chain combos to trigger turbo boosts, climb through progressively harder word tiers, and compete for top leaderboard spots[cite: 1].

## 🎮 Gameplay & Features

• Dynamic Typing Physics: Real-time typing speed and accuracy directly drive the motorcycle's acceleration and road animation[cite: 1, 2].
• Adaptive Difficulty Progression: Levels scale from common short vocabulary to advanced, complex words as your score increases[cite: 1].
• Combo & Turbo Boost: Maintain unbroken streaks to activate visual speed lines, screen shake, and speed-multiplying turbo boosts[cite: 1, 2].
• HTML5 Canvas Visuals: Custom-rendered 2D motorcycle animations, day/night procedural backdrops, particle exhaust, and floating score metrics[cite: 1, 2].
• Responsive & Mobile Ready: Full support for desktop mechanical keyboards and on-screen touch keyboards on mobile devices[cite: 1].
• Persistent High Scores: Track best runs, WPM (Words Per Minute), accuracy percentages, and combos stored via local storage[cite: 1].

## 🛠️ Tech Stack

• Framework: React 19[cite: 1]
• Language: TypeScript[cite: 1]
• Bundler & Tooling: Vite[cite: 1]
• Styling: Tailwind CSS v4[cite: 1]

## 🚀 Getting Started Locally

Prerequisites:
Ensure you have Node.js (v18 or newer recommended) and npm installed[cite: 1].

Installation:

1. Clone the repository
git clone https://github.com/laiqkhanjadoon/TYPING-GAME.git
cd TYPING-GAME

2. Install dependencies
npm install

3. Start the local development server
npm run dev
Open your browser and navigate to http://localhost:5173 to test the game[cite: 1].

4. Build for production
npm run build
The compiled single-file bundle will be output to the dist directory[cite: 1].

## 🕹️ Controls

Type Characters: A to Z keys[cite: 1]
Correction: Backspace[cite: 1]
Pause / Resume: Esc or P[cite: 1]
Mobile Input: Tap the screen or press the on-screen Keyboard button[cite: 1]
